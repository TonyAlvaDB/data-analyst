# SQL

So, I already know something about SQL. And, given that Excel looks to be a small challange, I decided to practice SQL together with Excel. 

So, here's what we are doing within the first 12 weeks of this path:

1. Base questions: I'll answer questions in different datasets using GROUP BY, HAVING, NULL and date functions. This will take 2 weeks and I'll use knowledge that I already have.
2. Joins and granularity: I'll join different tables and answer business questions. I also need to dive into granularity. For that I'll use [this article](https://medium.com/@harsh1995hg/understanding-data-granularity-why-the-level-of-detail-shapes-your-insights-and-how-to-avoid-abf742e4c31e). This will take 2 weeks
3. CASE WHEN: Create segments and measure each one of the segments. For this I'll see [this video](https://www.youtube.com/watch?v=RYIiOG4LsvQ) which belongs to a bootcamp I was doing 
4. Subquerys and CTEs: Nested querys. FOr subquerys I'll use [this video](https://www.youtube.com/watch?v=i5acg3Hvu6g) and for CTEs I'll use [this one](https://www.youtube.com/watch?v=UC7uvOqcUTs)
5. Window Functions: Use of ROW_NUMBER, ROW, RANK. I'll use [this vide](https://www.youtube.com/watch?v=7NBt0V8ebGk)
6. Window Functions 2: SUM OVER, LAG and LEAD: I'll use [this article](https://medium.com/@Samietex/sql-window-functions-explained-the-examples-that-actually-made-them-click-b66d9b000ce7)
7. Tipical Analysis: Here I'll dive into [funnel analysis](https://medium.com/design-bootcamp/digging-deeper-into-funnel-analysis-753c7707ddc2) and [cohort retention](https://userpilot.medium.com/cohort-retention-analysis-101-how-to-measure-user-retention-87d519adcb57)
8. Validation: I'll use [this](google.com/search?q=validation+sql&oq=validation+sql&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIKCAEQABgTGBYYHjIKCAIQABgTGBYYHjIKCAMQABgTGBYYHjIKCAQQABgTGBYYHjIKCAUQABgTGBYYHjIKCAYQABgTGBYYHjIMCAcQABgKGBMYFhgeMgoICBAAGBMYFhgeMgoICRAAGBMYFhge0gEINTE1OGowajSoAgCwAgA&sourceid=chrome&source=chrome.ob&ie=UTF-8) for validation
