# Excel (The old reliable)

So, here we are. Excel. It's always a good starting point.

But, what am I going to see here?

I'm going to study Excel during 7 weeks. Here's the specific point's I'll see:

1. Data cleaning: I'm going to take a [dataset](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning) and clean it. I will be using [this](https://medium.com/@chikachieze08/data-cleaning-and-transformation-in-excel-2f0599a54216) example to clean the dirty data.
2. Pivot tables and XLOOKUP: With the datase already cleaned, I'll build interesting pivot tables to answer a specific business question. I'll use [this](https://www.youtube.com/watch?v=bERwIzJZ-KA) video as a guide. Also, I'll use XLOOKUP to bring data from another tab. I will use [this](https://www.youtube.com/watch?v=dlBuWllegRg) video as a guide. 
3. Power Query: On this step, I'll repeat the same data cleaning of the first step, but using Power Query. For this I'll be using the [official documentation](https://learn.microsoft.com/en-us/power-query/), and [this video](https://www.youtube.com/watch?v=MMdcczmULrU). The idea is to automatize the cleaning steps.
4. Descriptive Statistics: Here, I'll use [this](https://mattchoward.com/estadistica-descriptiva-en-excel/) article as a guide, together with [this video](https://www.youtube.com/watch?v=kRZ3OfQAAJA) (it's in spanish). I'll describe the already cleaned dataset. I'll also be reading [this](https://www.redalyc.org/pdf/4867/486755026009.pdf) article I found.
5. Outliers, distribution and corelation: this is to reinforce the last point. For outliers i'll use [this video](https://www.youtube.com/watch?v=kRZ3OfQAAJA), for distribution I'll use [this one](https://www.youtube.com/watch?v=0tLF83IxwdY) and for corelation [this one](https://www.youtube.com/watch?v=8a_etQN-qso). I'll be building a historiagram and a box plot to help me achieve a final outcome. I'll also read [this article](https://medium.com/@alienoghli/the-essential-guide-to-a-b-testing-a84b853c16e0) related with A/B testing. 
6. Visualization: This week I'll read [Storytelling with data](https://github.com/ytx-readings/data-books/blob/main/books/data-visualization/storytelling-with-data-cole-nussbaumer-knaflic.pdf). I'll locate some graphics online and fix them using the *three rules*. Then, I'll transform an analisys into graphs.

Somewhere in between all this I'll see functions. In my opinion functions are not hard, I just need to know what they do.

I'm also sure that I'll not be in this 6 weeks, I think it's a lot. But I put it like this so I have some sort of order. My mind needs it

## The final goal

The idea is being able to clean data, answer business questions with pivot tables and XLOOKUP, write a few statistical phrases that someone would believe and tell a story with a graph. I'll upload a clean dataset with a pivot table and plots. Also, a readme explaining all.
